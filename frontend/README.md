# 🏝️ Socorro Suroy App

**A Capstone Project Showcasing the Beauty of Socorro Island, Philippines**

The Socorro Suroy App is a web application developed as part of a capstone project. It aims to digitally promote the island of **Socorro**, Surigao del Norte — highlighting its **tourist destinations, local delicacies, cultural identity, and barangay-level leadership**.

🌐 Live Site: [soroy-sa-socorro.vercel.app](https://soroy-sa-socorro.vercel.app/)

---

## 📸 Features

- 🗺️ **Tourist Destinations**
  - Lists and describes natural attractions such as beaches, mountains, and hidden gems.

- 🏘️ **Barangay Directory**
  - Displays barangay-level pages with information on local officials and must-visit spots.

- 🍲 **Local Delicacies**
  - Introduces the food culture of Socorro, showcasing unique and beloved dishes.

- 🚐 **Travel Info**
  - Contains travel fee estimates and directions to help guide tourists.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, PHP
- **Deployment:** Vercel
- **Other Tools:** Manual file structure (non-framework based)
